Board 2 of 2: where does the search field go, and where do the reference sections go so the list keeps its room?

Today: the window stacks list, footer buttons, Starter Packs with a long paragraph, and two collapsible sections (Spoken Punctuation, Voice Commands) that do not scroll. Opening Spoken Punctuation squeezes the list, and the owner reported that the window stops responding.

Direction: native macOS Sonoma/Tahoe window and popover, system font, dense list; signature element: the heard-as chips. Each variant shows the full window with the query “flor” typed (left) and a second state (right) that shows the room the list keeps. Anything the app does not have yet carries NEW.

Common to all three: column headers “Correct spelling” and “Heard as”, footer button “Add Entry”, and one explanation line under the toolbar. The count line follows the filter (“2 of 183 words”). Invented words only.

A — search in the toolbar, reference in a footer popover

Differs in: search sits top right in the toolbar (⌘F focuses it); Starter Packs become a menu button in the footer; Spoken Punctuation and Voice Commands move into a Reference button that opens a popover with its own scroll. The list takes everything that is left. The footer is tight at 720 pt: Export and Import stay, with slightly smaller buttons, so everything fits without a new menu.

Room for the list: full, about 10 rows. Cost: medium (footer buttons, popover, search). Nothing is squeezed, because the reference content never lives in the window.

B — search row above the list, collapsed reference panel below it

Differs in: search is a full-width row above the list (like History’s “Search history…”); under the list a bottom panel with three tabs (Starter Packs | Spoken Punctuation | Voice Commands), collapsed by default, at most 180 px tall, scrolling inside.

Room for the list: about 8 rows closed, about 4 with a panel open (the panel is capped, so the window never stops responding, but the list does shrink). Cost: medium (tabbed panel with capped height).

C — search in the toolbar, reference in its own window

Differs in: search as in A; Starter Packs and the reference sections leave the dictionary window for a separate “Dictation Reference” window, opened from a button on the popover’s Dictionary tab and from the Help menu. The dictionary window holds only list and footer. Starter Packs go with it, so importing a pack is one window away.

Room for the list: full, about 10 rows. Cost: larger (new window, a Help menu item, a popover button). Reference stays open next to the list for reading while you edit.
